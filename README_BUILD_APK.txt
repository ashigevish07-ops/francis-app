[SINHALA / SINGLISH GUIDE - ANDROID STUDIO NATHUWA APK EKA HADANNA]

STEP 1: GitHub eken Auto-Build karala .APK eka ganna (Vinadi 2i!)
1. Me ZIP file eka extract karanna.
2. GitHub.com ekata gihin aluth repository ekak hadanna (ex: francis-optimize-apk).
3. Extract karapu folder eke thiyena OKKOMA files & folders tika (".github" folder
   ekath ekka!) GitHub repo ekata upload/push karanna.
4. GitHub repo eke uda thiyena "Actions" tab ekata yanna.
5. "Build FRANCIS OPTIMIZE APK" workflow eka auto run wela vinadi 2kin green
   tick ekak ei.
6. Eka click karala yata "Artifacts" walin "FRANCIS-OPTIMIZE-APK" download
   karanna — eka athule real "FRANCIS-OPTIMIZE-v2.0.apk" eka thiyenawa!

STEP 2: MSI App Player / BlueStacks Root + 240 FPS Unlock karanna
1. MSI App Player eka sampurnayenma close karanna.
2. "PC_Tools\MSI_BlueStacks_Root_And_FPS_Unlock.bat" file eka
   Right-Click -> "Run as Administrator" karanna.
   (Meken Root access + 240 FPS lock eka unlock wenawa, backup ekakuth hadenawa).

STEP 3: Emulator eka athulata APK eka dala Blur karala Free Fire gahanna!
1. MSI App Player open karala "FRANCIS-OPTIMIZE-v2.0.apk" eka emulator
   screen eka udata drag & drop karala install karanna.
2. Emulator eka athulen "FRANCIS OPTIMIZE" app eka open karanna.
3. Root permission illuwoth "Allow / Grant" denna.
4. "FREE FIRE" select karala "MAX BLUR" ho "POTATO GL" preset eka dala
   (kemathi ganakata sliders adjust karala) "APPLY BLUR & LAUNCH GAME" obanna!
5. Game eka gahala iwara unama notification bar eken ho app eke
   "RESTORE 100%" eken apahu normal screen ekata ganna puluwan.
